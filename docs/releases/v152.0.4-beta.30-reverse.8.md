## 版本说明

Camoufox Reverse `reverse.8` 固定基于 Firefox `152.0.4-beta.30`，包含 reverse.7 的快速退出落盘及中止请求部分响应修复，并更新 Playwright 初始化脚本的 main-world 识别。

## 修复

- 原生退出前排空 PropertyTracer，保留 metadata 和 off ACK。
- 失败请求保留已收到的响应字节，明确标记部分响应。
- 识别 Playwright 初始化脚本 guard 后的 `mw:` 前缀，使严格 CSP 页的自动化初始化脚本正确进入主世界；不修改页面 CSP。
- Python 请求头查询遇到 route override 竞态时保留采集缺口，不回退到修改前的请求头。
- 构建脚本核对 tracer、网络观察器和 FrameTree 源码，拒绝给过期源码打新版本标签。

## 兼容性与边界

- Selector：`whitenightshadow/152.0.4-beta.30-reverse.8`，与旧版本并存，不修改 active 配置。
- PropertyTracer protocol 1 和 77 个属性 hook 保持兼容；并非全 JSVM 指令追踪。
- 请求发起栈需配套 MCP 源码及新启动的 MCP 进程。完全相同的并发请求标记 ambiguous，不猜测关联。
- 流式响应等待有界；超时或缺失证据标记 incomplete。Google 登录成功及 id_token 获取不属于此次无凭据冒烟验收。
