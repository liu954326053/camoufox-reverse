## 版本说明

Camoufox Reverse `reverse.7` 固定基于 Firefox `152.0.4-beta.30`，修复快速退出丢失 PropertyTracer 关闭证据及中止请求丢失已接收响应字节的问题。

## 修复

- Firefox `AppShutdown::DoImmediateExit` 在快速退出前停止 tracer、排空缓冲并保存 metadata 和 off ACK。
- 正常退出保留最终 ACK；metadata 发布和文件关闭失败保留错误状态。
- Juggler 在请求失败前也缓存已经收到的响应字节；请求失败事件保持原样。
- 配套 Python runtime 用 `captured_partial` 标记失败请求的部分响应，并从 Firefox 原始请求事件的有序头数组恢复因导航竞态导致的头查询失败。
- 构建前拒绝过期 tracer/network additions 或缺失退出补丁的已准备源码树。

## 兼容性与边界

- Selector：`whitenightshadow/152.0.4-beta.30-reverse.7`；与 `reverse.6` 并存，不修改 active 配置。
- PropertyTracer protocol 1、77 个原生属性 hook 保持兼容。
- 调用栈采集还需要配套更新 MCP 服务器；替换浏览器包不会自动重载已经运行的 MCP Python 进程。
- 不把部分响应标为完整响应，不忽略未确认的原生退出，不把原生插桩点当作 JS 值生成链。
