## 版本说明

Camoufox Reverse `reverse.9` 固定基于 Firefox `152.0.4-beta.30`，在 `reverse.8` 之上补齐被动取证的归因与证据完整性：引擎层 initiator 栈、document 302 直通、MCP 层引擎请求/响应体捕获，并新增免 clone 仓库的 Release 直装自举包。

## 主要变更

- NetworkObserver 在 content 进程 `http-on-opening-request` 同步读取 `Components.stack`，被动模式（不装页面世界 hook）下 fetch/XHR 也有 initiator 栈；导航类请求记 null 是自描述而非丢失。
- vm_loop route 层新增 document 302 直通判据，重定向链原样交还浏览器遍历；严格 CSP 页面不注入页面世界 hook，CSP 护栏保持不变。
- MCP 网络证据透出引擎体捕获：`engine_request_body` / `engine_response_body`（base64 + size + truncated 自描述），二进制无损，引擎侧零改动。

## 兼容性

- Selector：`whitenightshadow/152.0.4-beta.30-reverse.9`，与旧版本并存，不修改 active 配置。
- PropertyTracer protocol 1 和 77 个属性 hook 保持兼容；引擎体字段需配套本包内的 MCP 源码，运行中的 MCP 进程需重启才会加载。
- 新增 `camoufox-reverse-agent-reverse.9.tar.gz` 自举包：包根 `install.sh` 一键完成 Python 包安装、浏览器二进制下载校验安装、Skill 安装与 MCP 配置示例生成；浏览器资产命名不变，版本区分靠 release tag。

## 验证

- 本机 mac.arm64 构建通过 `scripts/validate_reverse_build.py` 契约校验；scripts/tests、pythonlib、integrations MCP 三套测试全绿。
- 瑞数目标 sso.cnipa.gov.cn 被动全链路实测（412 挑战页、动态 JS 全文、签名 XHR 与 initiator 栈闭环）；signup.live.com 302 链直通与上市公司公示系统零污染探针实测通过。
