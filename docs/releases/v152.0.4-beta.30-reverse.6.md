## 版本说明

Camoufox Reverse `reverse.6` 固定基于 Firefox `152.0.4-beta.30`，并包含可持久化的 PropertyTracer 事件损失元数据。

## 主要变更

- 状态文件记录 `events`、`dropped` 和写入错误状态。
- 每个 trace session 生成 `traces/*.meta.json` sidecar，支持关闭后的完整性校验。
- 打包、安装器和运行时统一锁定 `reverse.6` 及 77 个 trace hook。

## 兼容性

- 浏览器 selector：`whitenightshadow/152.0.4-beta.30-reverse.6`。
- 与当前 Python reverse runtime、project-scoped MCP bridge 和 PropertyTracer protocol 1 配套。
- 普通 Camoufox 安装仍可并存，安装器不会修改 active 浏览器配置。

## 验证

- 原生 PropertyTracer、源码注入器和 reverse browser foundation 测试通过。
- 发布流水线会校验 archive 内的版本、能力标记、状态字段和 metadata sidecar 契约。

**完整变更**：基于 `reverse.5` 增加可验证的事件损失元数据和版本一致性校验。
